# YouTube-Finish-By-Speed-Planner
Plan how fast to watch a YouTube video to finish by a clock time you choose. Steady Pace gives one constant speed; Sprint Start runs at max speed first, then 1×, so a later pause can be recovered. Also helps you catch up to livestreams. Optional Auto-set applies the plan for you (off by default). Ignores stitched-in ads. Remembers your settings.
